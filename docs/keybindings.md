# Keyboard shortcuts

All shortcuts as wired in the menus, toolbar, and viewport. Single-letter
culling and tool keys are window-level — they fire whether the film strip or the
image area has focus.

## File

| Key | Action |
|---|---|
| `Ctrl+O` | Open file |
| `Ctrl+Shift+O` | Open folder |
| `Ctrl+S` | Save adjustments (`.xmp` sidecar) |
| `Ctrl+E` | Export… |
| `Ctrl+Q` | Quit |

## Edit

| Key | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+Shift+C` | Copy settings… |
| `Ctrl+Shift+V` | Paste settings… |

## View

| Key | Action |
|---|---|
| `Ctrl+0` | Reset zoom to fit |
| `F8` | Toggle Adjustments panel |
| `F9` | Toggle Film Strip |
| `F11` | Full screen |
| `F12` | Hide panels (lights-out) |
| `S` | Toggle soft-proofing |
| `J` | Toggle clipping overlay (highlights + shadows) |
| `\` (hold) | Show original (before/after) |
| `Esc` | Cancel the active tool, or restore panels when in full-screen / lights-out |

Zoom: scroll wheel (0.05×–32×). Pan: `Alt`+drag or middle-button drag.

## Navigation

| Key | Action |
|---|---|
| `←` | Previous image in folder |
| `→` | Next image in folder |

## Tools

| Key | Action |
|---|---|
| `C` | Crop tool (toggle) |
| `M` | Masks (local adjustments) tool |
| `Q` | Spots (clone) tool |
| `Enter` | Commit the active tool |
| `Esc` | Cancel the active tool |
| `Ctrl+]` | Rotate 90° clockwise |
| `Ctrl+[` | Rotate 90° counter-clockwise |
| `X` | Flip crop orientation (portrait ↔ landscape, while cropping) |

The Straighten and White Balance picker tools are activated from the toolbar.

## Culling

Rating and colour-label keys apply to the current image (and appear in the film
strip's right-click menu).

| Key | Action |
|---|---|
| `1`–`5` | Set star rating (1–5) |
| `0` | Unrated |
| `X` | Reject |
| `R` | Red colour label |
| `Y` | Yellow colour label |
| `G` | Green colour label |
| `B` | Blue colour label |
| `P` | Purple colour label |
